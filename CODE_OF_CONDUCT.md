# Code of Conduct

## Our Standards

Contributors and maintainers are expected to help maintain a respectful, professional, and inclusive project environment.

Examples of positive behavior include:

* Being respectful and constructive in discussions and code reviews.
* Assuming good intent and focusing on technical issues rather than individuals.
* Giving and receiving feedback professionally.
* Respecting different levels of experience, backgrounds, and viewpoints.
* Keeping discussions relevant to the project.

Unacceptable behavior includes:

* Harassment, discrimination, or personal attacks.
* Trolling, insulting, or deliberately disruptive behavior.
* Publishing private or sensitive information without permission.
* Threats, intimidation, or targeted abuse.
* Any other conduct that would reasonably make the project environment unsafe or hostile.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Maintainers may take any action they consider appropriate in response to unacceptable behavior, including:

* Removing inappropriate comments or contributions.
* Closing or restricting participation in project discussions.
* Temporarily or permanently restricting participation in the project.
* Reporting serious or unlawful behavior to the appropriate authorities when necessary.

## Reporting

If you experience or witness unacceptable behavior, please report it privately to the project maintainer rather than creating a public issue.

For security vulnerabilities, **do not use this process**. Follow the instructions in [`SECURITY.md`](SECURITY.md).

## Scope

This Code of Conduct applies to project spaces, repositories, discussions, issues, pull requests, reviews, and other interactions related to the project.

## Responsibility

By participating in this project, you agree to follow this Code of Conduct and help maintain a respectful and constructive open-source community.
